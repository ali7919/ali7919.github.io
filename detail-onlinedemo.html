Online Demo

A third-person multiplayer prototype on Photon PUN2

Overview
  • Category Unity — PUN2
  • Start date January 2022
  • Repository GitHub

I took the third-person template provided by Unity and turned it into an online game using PUN2 (Photon Unity Networking).

The way it works is simple: someone becomes the host and others can join. I also coded a prize spawning-and-collecting system that is operated by the host — the prizes (yellow balls) spawn and sync online — and added a dance animation to the animation system as well.

The whole project is open source and you can find it on my GitHub.
