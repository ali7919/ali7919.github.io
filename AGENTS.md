This is a static portfolio and project showcase website. 
It uses plain HTML, CSS, JavaScript, and vendor libraries like Bootstrap, Swiper, and Isotope.

## General Guidelines
- Modify HTML files in the root directory for content updates.
- Custom styling should go into assets/css/style.css.
- Custom JavaScript should go into assets/js/main.js.
- Respect existing vendor libraries in the assets/vendor/ folder, do not modify them.
