Chess

Chess with a minimax AI, written in Java

Overview
  • Category Android Studio — Java
  • Start date November 2018
  • AI Minimax — depth 3

A chess game with two game types — one player and two player — made in Android Studio with Java. The AI is a minimax algorithm with a search depth of 3.

Tapping a piece highlights every square it can move to, tapping one of those squares makes the move, and tapping the selected piece again cancels the selection and returns to piece-picking mode.
