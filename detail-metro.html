MetroYab

Finding the nearest metro station in Tehran and Karaj

Overview
  • Category Android Studio — Java
  • Start date June 2019
  • Installs 700+ active
  • Project URL CafeBazaar

MetroYab is an Android app that shows you the nearest subway in Tehran and Karaj, and includes some information about the stations.

It finds the closest station to your current position or to any location you pick, and it includes the Tehran metro stations and lines.

MetroYab is available on CafeBazaar with 700 active installs.
