FilmZ

Movie discovery and details, built with MVVM

Overview
  • Category Android Studio — Kotlin
  • Start date January 2021
  • Repository GitHub

FilmZ is an app you can use to search for movies and view their details — cast, a summary and a few other things. I made it with Kotlin and implemented an MVVM architecture.

Movies are searched on IMDb and you get the rating, runtime, release year, plot summary and cast. Any movie can be archived after the search and is stored in a local database.

The app was built to sharpen my Kotlin and native Android best practices, using the MVVM pattern, Kotlin Coroutines, Retrofit, the Android architecture components (Room, LiveData, ViewModel) and the Navigation Component. It is open source and you can find it on my GitHub.
