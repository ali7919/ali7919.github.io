UBank

A self-contained bank transaction manager for Android

Overview
  • Category Android Studio — Java
  • Start date May 2019
  • Status On hold

UBank is a self-contained bank transaction manager that reads all of your messages, extracts the ones that come from a bank, analyses them, builds a corresponding model and forms its own database. That database is then used to give the user insights into their income, spending, overall balance and portfolio.

On top of that model — bank, bank account, transaction — it adds a set of features: tagging transactions and analysing the database by tag, tracking debts and receivables, setting spending caps per bank or per tag, and charting transactions over any range with filters such as transaction type, tag or bank.

I started this project alone and a friend joined me later. It is currently on hold, as the app grew and the development process became harder to keep up with.
