Routino

A habit tracker for Android

Overview
  • Category Android Studio — Java / Kotlin
  • Start date January 2020 (Bahman 98)
  • Project URL CafeBazaar

Routino is a habit tracker which a friend and I worked on together. Aside from the database layer, I developed and designed the rest of the app end-to-end — from the UI and user experience to the underlying logic and publishing flow.

Routino was published on CafeBazaar, the largest Android app market in Iran, and was selected by CafeBazaar's editors to be featured on the home page. It reached 5,000 active installs and was also promoted for a month on the CharKhoneh market's home page.
